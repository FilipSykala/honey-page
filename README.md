# 🐝 honey page

strona internetowa z interaktywną mapą pasiek, do łączenia lokalnych pszczelarzy z potenjalnymi kilentami

## 🚀 Funkcjonalności

- interaktywna mapa
- profile pszczelarzy
- blog
- sortowanie produktów

## 🛠️ Wykorzystane technologie

- Język: JavaScript, Html i Css
- mapa: Leafelet
